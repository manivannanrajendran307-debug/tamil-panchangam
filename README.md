# Ålesund Tamil Panchangam

Tamil Panchangam / Horai / Gowri Panchangam for Ålesund, Norway.

## Date range
18 November 2026 through 31 December 2037.

## Main calculations
- Ålesund local sunrise and sunset
- Tamil month, date and 60-year Tamil year
- Tithi and end time
- Nakshatra and end time
- Day and night Gowri Panchangam
- Day and night Horai
- Rahu Kalam
- Yamagandam
- Kuligai
- iPhone-friendly PWA with offline astronomy engine

The Gowri table follows the traditional Pambu Panchangam sequence used by Drik Panchang. Drik Panchang identifies Amirdha, Dhanam, Uthi, Laabam and Sugam as favourable and Rogam, Soram and Visham as unfavourable.

Tamil Daily Calendar values are Indian-time references; this app calculates the clock times locally for Ålesund instead.

## Enable the live iPhone app

In GitHub:
1. Open **Settings** for this repository.
2. Open **Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. Return to **Actions** and run **Deploy to GitHub Pages**.

The workflow is already included in `.github/workflows/pages.yml`.

The app URL will be:
https://manivannanrajendran307-debug.github.io/tamil-panchangam/

On iPhone Safari: open the app → Share → Add to Home Screen → Add.
